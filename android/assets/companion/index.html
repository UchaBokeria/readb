How the private link works

WireGuard is built into readb. No separate VPN app is needed. Only the server address in your setup uses this tunnel.

Android supports one active VPN. Starting readb replaces another active VPN. You choose when to start.

A tunnel being active does not prove that your server accepted the device. Check secure ADB and the server dashboard too.
